🇮🇩 Suara khusus Bahasa Indonesia

Aplikasi hanya akan memakai suara Bahasa Indonesia. Jika perangkat belum menyediakannya, aplikasi tidak akan menggantinya dengan suara bahasa Inggris.

Sedang memeriksa ketersediaan suara Bahasa Indonesia.

Suara ini masih merupakan suara sintetis dari perangkat. Untuk hasil benar-benar seperti manusia, gunakan rekaman Ayah/Ibu.

Rekam kalimat dengan suara Ayah/Ibu, misalnya: “Halo, Bilqis!”. Rekaman hanya disimpan di browser perangkat ini, tidak dikirim ke server.

Memuat rekaman…

Kalimat yang belum direkam akan tampil sebagai teks tanpa suara sintetis. Rekam kalimat sapaan dan pujian terlebih dahulu, lalu kalimat huruf yang sering Bilqis mainkan. Mikrofon aktif hanya ketika Anda menekan Mulai merekam.

Aktivasi suara dimulai setelah tombol ditekan. Gunakan Chrome atau Edge terbaru. Perizinan mikrofon bisa berbeda untuk file HTML lokal; unggah rekaman audio jika mikrofon tidak tersedia. Bintang tersimpan di perangkat ini saja.
